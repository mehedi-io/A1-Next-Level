# TypeScript Practice

A small TypeScript practice project with examples of common language features and short written notes.

## Project Structure

- `src/solve.ts` contains the TypeScript exercises.
- `dist/` contains JavaScript generated by the TypeScript compiler.
- `Type_Alias_vs_interface.md` compares type aliases and interfaces.
- `Type_Narrowing.md` introduces type narrowing.
- `index.html` loads the compiled `dist/solve.js` in a browser.

## Build and Run

With Node.js and the TypeScript compiler (`tsc`) available, run this from the project root:

```powershell
tsc
```

To run the compiled exercises with Node.js:

```powershell
node .\dist\solve.js
```

To view the browser example, build first and then open `index.html`.

## Topics Practiced

The exercises cover optional parameters, union types and type narrowing, tuples, generics, interfaces, `keyof`, classes, access modifiers, and asynchronous functions with Promises.
